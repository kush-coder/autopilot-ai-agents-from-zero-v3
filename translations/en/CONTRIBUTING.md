# Contributing to AI-Agents-From-Zero

Thank you for your interest in this project 🙌

This project aims to build a hands-on tutorial for AI Agents, from zero basics to enterprise-level implementation.
All forms of contribution are welcome.

---

## 📌 What Can You Contribute?

We welcome the following types of contributions:

- Fix documentation errors / typos
- Supplement case explanations
- Add hands-on project examples
- Optimize code structure
- Provide better Prompt templates
- Improve RAG / Agent architecture solutions
- English translation (future plan)

---

## 🛠 How to Contribute?

### 1️⃣ Fork the Repository

Click Fork in the upper right corner

### 2️⃣ Create a New Branch

```bash
git checkout -b feature/your-feature-name
```
