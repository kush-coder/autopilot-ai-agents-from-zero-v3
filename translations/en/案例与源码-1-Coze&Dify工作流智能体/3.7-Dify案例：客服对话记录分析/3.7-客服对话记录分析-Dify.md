# 3.7 - Dify Case Study: Customer Service Conversation Log Analysis

---

## Overview of This Case

### Nodes Used

| Node Name                | Type / Capability   | Purpose                                                                                                                         |
| ----------------------- | ------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| **Excel to JSON**       | Document parsing / format conversion | Converts the uploaded xlsx into structured data, outputting `text` (a JSON string of the conversation list) and `json`.                                               |
| **Process ROWS into LIST** | Code node            | Escapes `text` and then `json.loads`, obtaining a list of dictionaries `result` for the iteration node to traverse.                                                 |
| **Iteration**                | Loop                | Executes the internal subflow (extraction, sentiment analysis, issue classification, summarization, aggregation) for each conversation record in `result`.                                           |
| **Extract ID and MSG**      | Code node            | Extracts `row` and `msg_id` from the current iteration item `history_message`, outputting them as `id` and `msg`.                                                  |
| **Sentiment Analysis**            | LLM + structured output | Determines the user's sentiment level based on the conversation content (very negative/negative/neutral/positive/very positive), outputting `rank` and `reason`.                                  |
| **Issue Classification**            | LLM + structured output | Categorizes the conversation into product issues, service issues, experience issues, and specific tags (such as quality defects, slow response complaints, etc.), outputting `product`/`content`/`experience` arrays. |
| **Aggregate Analysis Results**        | Code node            | Merges the issue classification, content summary, sentiment analysis results with `msg_id` and `msg` into a unified `result` structure.                                            |

### Technical Highlights

- **Workflow and file input**: This case uses a Dify Workflow (not Chatflow). The start node is configured to receive a `input_file` (xlsx). After the user uploads customer service conversation data, the entire flow executes once and outputs an analysis list.
- **Excel → JSON → List**: First, the "Excel to JSON" node is used to obtain `text` (a JSON string containing `msg_id` and `history_message`), which is then processed by a code node to handle escaping and parse it into a list of dictionaries for iteration.
- **Parallel multi-tasking within iteration**: Each conversation within the iteration sequentially passes through "Extract ID and MSG" → "Sentiment Analysis", "Issue Classification", "Content Summary" (three LLM nodes, which can run in parallel) → "Aggregate Analysis Results" code node, merging sentiment, classification, summary with the original id/msg into a single analysis result.
- **LLM and structured output**: Both sentiment analysis and issue classification have structured output enabled. Sentiment analysis outputs `rank` and `reason`, while issue classification outputs `product`/`content`/`experience` arrays, making it convenient for downstream code nodes to parse stably.
- **Code nodes**: There are two — ① Process ROWS into LIST: escapes `text` and then `json.loads` to obtain `result`; ② Aggregate Analysis Results: combines `problems`, `summary`, `senti_analysis`, `msg_id`, `msg` into a single `result`, which is aggregated by the end node into a complete list after iteration completes.

### Workflow Overview

```
开始(input_file: xlsx)
    ↓
Excel 转 JSON → text（对话列表 JSON 字符串）、json
    ↓
将 ROWS 处理为 LIST(代码：text 转义 + json.loads) → result（字典列表）
    ↓
迭代(result)：对每条 row →
    ↓
    提取 ID 和 MSG(代码) → id, msg
    ↓
    情感分析(大模型：msg) → rank, reason
    问题分类(大模型：msg) → product, content, experience
    内容总结(大模型：msg) → summary(text)
    ↓
    聚合分析结果(代码) → result{ content, experience, product, msg_id, msg, summary, rank, reason }
    ↓
结束：输出所有迭代 result 组成的列表
```
