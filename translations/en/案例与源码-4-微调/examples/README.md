## Viewing Actual Inputs

`thinking-control/prompt-inspection.json` saves the complete inputs generated by the two templates, token IDs, and checks for isolation between the input ending and the answer. View `decoded_input` to read the text actually received by the model; view `input_ids` to check tokens one by one.

In the LLaMA-Factory version locked for this example, `qwen3_nothink` does not add an empty thinking block, while `qwen3` combined with `enable_thinking=False` adds one at the assistant start position. The two wrappings of the three inputs differ only in the last four tokens; the user messages are identical, and reference answers do not enter the generation input.

All four groups use the same Qwen3-0.6B base model; groups that require an Adapter load the same Adapter. Actual parameters are all FP16, batch size 1, sampling disabled, generation limit 256, repetition penalty 1.0, seed 42. What the comparison changes is the inference template and whether an Adapter is loaded; the Adapter's training template is `qwen3_nothink`.

After adding the empty block to the original model, these three responses no longer contain analysis passages, but they still have English rewrites, omitted words, and repetitions. This indicates that input wrapping affects response form, and cannot guarantee that all inputs are effective or assert that keyword quality is already acceptable. Actual inputs are shown in `thinking-control/prompt-inspection.json`, and the four response files are placed directly in `thinking-control/`, with filenames indicating model state, template, and the disabled-thinking setting.

## Recalculating Template Examples Locally

The following command runs in the **course project root directory**, using Python 3.10 or higher. It only reads saved responses and does not generate new predictions:

```bash
thinking_review_dir=$(mktemp -d)
python3 案例与源码-4-微调/examples/thinking-control/convert_control_predictions.py \
  --reference 案例与源码-4-微调/examples/thinking-control/验证输入.jsonl \
  --predictions 案例与源码-4-微调/examples/thinking-control/原始模型-qwen3-关闭思考.jsonl \
  --template qwen3 \
  --output "$thinking_review_dir/原始模型-qwen3-关闭思考.jsonl"
python3 案例与源码-4-微调/evaluate_keywords_predictions.py \
  --reference 案例与源码-4-微调/examples/thinking-control/验证输入.jsonl \
  --predictions "$thinking_review_dir/原始模型-qwen3-关闭思考.jsonl" \
  --require-all \
  --output "$thinking_review_dir/原始模型-qwen3-关闭思考-评分.json"
```

All four groups share `examples/thinking-control/验证输入.jsonl`. When viewing or recalculating, select the response file and template parameters according to the table below; these files are all located in `examples/thinking-control/`:

## Recalculating Prompt Examples Locally

`prompt-comparison/data/` saves the complete inputs and reference answers corresponding to the three prompts, and the four original response files are placed directly in `prompt-comparison/`. The original model uses A, B, and C respectively; after loading the Adapter, the same B input is used. Each group has 10 entries, 40 in total.

All four groups use Qwen3-0.6B, the `qwen3_nothink` template, the disabled-thinking setting, FP16, batch size 1, input limit 2,048 tokens, sampling disabled, generation limit 256, repetition penalty 1.0, and seed 42. Under these settings, the original model still outputs analysis, so both format and content must be checked; response form cannot be judged solely by the disabled-thinking setting.

Taking the original model group B as an example below, run in the **course project root directory**; only saved responses are converted and scored:

```bash
prompt_review_dir=$(mktemp -d)
python3 案例与源码-4-微调/convert_keywords_predictions.py \
  --reference 案例与源码-4-微调/examples/prompt-comparison/data/keywords_prompt_b.jsonl \
  --predictions 案例与源码-4-微调/examples/prompt-comparison/原始模型-提示词B.jsonl \
  --output "$prompt_review_dir/原始模型-提示词B.jsonl"
python3 案例与源码-4-微调/evaluate_keywords_predictions.py \
  --reference 案例与源码-4-微调/examples/prompt-comparison/data/keywords_prompt_b.jsonl \
  --predictions "$prompt_review_dir/原始模型-提示词B.jsonl" \
  --require-all \
  --output "$prompt_review_dir/原始模型-提示词B-评分.json"
```
