# Qinghe Document Desk Product Description

> This is a fictional product created for the course and is used only for practicing document Q&A data generation. It does not represent the capabilities or commitments of any real service.

Version: Teaching Edition v1.0; Document Number: QH-MANUAL-001.

## S01 Workspace and Members

The trial workspace of Qinghe Document Desk can accommodate up to 5 members, including the workspace owner. Only the owner can invite or remove members.

## S02 Uploading Files

Qinghe Document Desk supports uploading PDF, DOCX, Markdown, and TXT files, and a single file cannot exceed 20 MB. Scanned PDFs must first undergo OCR and have the recognized text checked before they are uploaded for processing.

## S03 Deletion and Recovery

Deleted documents are kept in the recycle bin for 7 days, during which only the workspace owner can restore them. After recovery, the document returns to the folder it was in before deletion.

## S04 Exporting Tasks

The task list can only be exported by the workspace owner. The export format is UTF-8 encoded CSV, and the exported content includes all tasks under the current filter conditions, not just the current page.

## S05 Summary Notifications

Task summaries are sent via email at 9:00 AM every day, covering the previous day's task summary. Only members who have actively subscribed will receive the email, and the workspace owner can disable summary sending for the entire workspace.
